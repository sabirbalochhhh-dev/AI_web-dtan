## HealthCare Pharmacy Website

Good morning everyone, and thank you for listening. Today I am presenting my final year project titled HealthCare Pharmacy Website. This project was developed to create a modern and professional online platform for a pharmacy business. The website is designed for two main users: customers who visit the public site, and administrators who manage the content through a secure admin panel.

The main business problem I focused on was the lack of a digital and organized system for many small pharmacies. In many cases, pharmacies still depend on manual methods for sharing information, managing medicines, and handling customer inquiries. This can cause delay, confusion, and poor communication. My project solves this problem by providing a website where customers can easily find medicine information, view pharmacy details, and contact the store, while administrators can manage everything from one secure place.

The website includes several important pages. The Home Page gives a welcoming first impression with a modern design, pharmacy highlights, and important information. The About Page explains the mission, values, and services of the pharmacy. The Medicines Page allows visitors to browse available medicines and search by category. The Contact Page provides the contact details and includes a form where users can send their messages directly to the pharmacy.

One of the main features of the project is the Admin Login page. Only authorized users can access the admin area. After login, the admin is taken to the Dashboard, which shows summary information about medicines, categories, pharmacists, and gallery items. From the dashboard, the admin can navigate to different management sections easily.

Another important part of the project is CRUD functionality. CRUD stands for Create, Read, Update, and Delete. I implemented CRUD operations for medicines, categories, pharmacists, and gallery items. This means the admin can add new records, view existing data, edit details when needed, and delete records if they are no longer required. This makes the system functional and practical for real administration work.

The project also includes an Image Upload system. Administrators can upload images for medicines, pharmacists, and gallery content. These images are stored in the project folder and displayed on the website. This feature improves the overall appearance of the website and makes the content more attractive and professional.

The database is another important part of the system. I used MySQL to store the data in related tables such as users, categories, medicines, pharmacists, gallery, and contact messages. This database design helps organize the information properly and supports future expansion of the system.

The website was also designed to be responsive. This means it works well on different screen sizes, including desktops, tablets, and mobile phones. The layout adjusts automatically so users can access the website easily from any device. This is very important because many users today browse websites using smartphones.

For the development of this project, I used several AI tools to support my work. I used ChatGPT for ideas, content generation, and understanding programming concepts. GitHub Copilot helped me by suggesting code and speeding up development. I also used Gemini for documentation support and debugging help. These tools made the development process easier and helped improve the quality of the project.

During the development process, I faced some challenges. One challenge was connecting the PHP code with the MySQL database correctly. Another challenge was making sure the image upload system worked properly and handled errors smoothly. I also had to ensure that the admin panel remained secure while still being easy to use. However, by testing carefully and improving the code step by step, I was able to solve these issues successfully.

In conclusion, this project successfully combines website design, database management, and secure administration in one system. It provides a professional online presence for a pharmacy and also gives the administrator a practical tool to manage the business content efficiently. I believe this project demonstrates my understanding of web development and my ability to build a complete and functional system. Thank you.
